## 通用归集清单

每类活动建议归集以下材料：

- 活动通知 / 实施方案
- 评审标准 / 评分细则
- 参赛（申报）材料模板
- 获奖名单
- 优秀作品 / 典型案例
- 活动总结与简报

## 命名建议

`年份-活动名称-材料类型-版本`，例如：`2026-微课评选-评审标准-v1.pdf`
