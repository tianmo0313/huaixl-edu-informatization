## 使用说明

- 每个板块设有 README 作为索引，列出应归集的材料清单和管理要点。
- 具体资料文件可上传到对应子目录，命名建议：`年份-名称-版本`，如 `2026-微课评选通知-v1.pdf`。
- 待办事项、问题反馈可用「议题（Issue）」记录，便于跟踪。
- 需要修改内容时，直接告诉 AI 助手即可。
